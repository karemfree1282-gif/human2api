# Governance

Human2API begins as a maintainer-led open source project. The repository owner merges changes and publishes releases. We intend to add more maintainers as trusted contributors emerge.

Priorities: user safety, reproducible automation, portability, and vendor neutrality. Changes that weaken privacy defaults or execute unexpected side effects need explicit review and tests.

Feature requests and design proposals belong in GitHub issues/discussions once enabled. Significant architectural changes should begin as a design issue before implementation.

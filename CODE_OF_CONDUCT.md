# Code of Conduct

This project follows the spirit of the Contributor Covenant: be welcoming, respectful, patient and constructive. Harassment, threats, discrimination, publishing private information, and personal attacks are not acceptable. Disagreements should focus on code and behavior, not people.

Report conduct concerns privately to a maintainer through a private channel listed in the repository once one is available. In the interim, use GitHub issue moderation without publishing identifying details. Maintainers may remove abusive content and suspend participation.

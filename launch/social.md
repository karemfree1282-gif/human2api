# Social media launch copy (draft)

**Short version**

What if you could teach an AI tool a browser task by doing it once?

Human2API records browser interactions, turns inputs into runtime variables (without saving form values), and exports a local MCP tool or REST API. Open source, Python/Playwright, Apache-2.0. v0.1 alpha.

See the 30-second fake-invoice demo and source: https://github.com/karemfree1282-gif/human2api

**30-second screencast storyboard**

0–5s: Open Human2API dashboard, click the fake invoice demo.
5–13s: Press New recording, fill customer and amount, click Create and Stop & save.
13–20s: Show the resulting JSON with `{{customer_name}}` and `{{amount}}`, no saved values.
20–27s: Run via CLI with different inputs; show verification and downloaded text invoice.
27–30s: Show the code repo and the MCP tool schema. Caption: Local-first. Inspectable. Open source.

Only record footage from a working build; do not create fake terminal outputs.

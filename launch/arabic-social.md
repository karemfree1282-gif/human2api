# Arabic launch announcement (publish only after live repo and passing CI)

عملت مشروع Open Source جديد اسمه Human2API 👨‍💻

الفكرة: تسجل مهمة على موقع ويب مرة واحدة، وبعدها تحول الخطوات لملف قابل للمراجعة وإعادة التشغيل من CLI أو REST API أو MCP (لأي عميل AI متوافق).

المشروع مجاني ومفتوح المصدر، ويشتغل محليًا باستخدام Python وPlaywright. البيانات اللي بتكتبها أثناء التسجيل بتتحول لمتغيرات بدل ما تتحفظ كما هي، لكن لازم تراجع روابط الصفحة والمحددات قبل مشاركة أي Workflow.

الإصدار الأول Alpha ويدعم Chromium والصفحة الأساسية فقط، ولسه مفيش دعم لتطبيقات ويندوز أو أندرويد، ولا إصلاح AI تلقائي.

الكود والتجربة: https://github.com/karemfree1282-gif/human2api

أي تجربة أو مشكلة قابلة لإعادة الإنتاج هتساعد جدًا في تطويره. مش مطلوب تقييم أو نجوم؛ المطلوب ناس تجرب وتقول إيه اللي اشتغل وإيه اللي محتاج يتحسن.

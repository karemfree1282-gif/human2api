# Product Hunt launch draft (use only after the GitHub URL, CI, and site are live)

**Name:** Human2API

**Tagline:** Turn a recorded browser task into a local MCP tool or REST API.

**Short description:** Human2API is an Apache-2.0 open-source browser automation recorder. Record clicks and forms in Chromium, inspect the generated JSON, replace values with runtime inputs, then invoke the workflow from a CLI, local REST endpoint, or an MCP-compatible agent. No separate account or model subscription is needed.

**First comment:** I built this because many browser tasks can be automated deterministically without asking an AI to guess each click. The first release is deliberately narrow: one Chromium tab, Playwright replay, explicit write approval, and a fake-invoice demo. It is not yet a desktop agent or autonomous UI repair system. Feedback and reproducible bugs are very welcome.

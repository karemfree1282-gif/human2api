# Human2API — دليل عربي سريع

Human2API مشروع مفتوح المصدر (Apache 2.0) لتسجيل مهمة داخل صفحة ويب في Chromium ثم إعادة تشغيلها باستخدام Playwright، أو تقديمها كأداة MCP وواجهة REST API محلية.

**مهم:** النسخة 0.1 Alpha لا تتحكم في تطبيقات ويندوز أو أندرويد، وليست وكيل AI مستقلاً ولا تصلح الواجهات المعطلة تلقائيًا. هذه قدرات مستقبلية مقترحة وليست مميزات حالية.

## التشغيل

يلزم Python 3.10 أو أحدث ومتصفح Chromium يدعمه Playwright.

```bash
python -m pip install -e .
python -m playwright install chromium
h2a serve
```

افتح `http://127.0.0.1:8765` ثم جرب المثال الوهمي للفواتير من `/demo`.

```bash
h2a check create_invoice
h2a run create_invoice --data '{"customer_name":"Test","amount":25.5}' --approve
```

لتسجيل مهمة جديدة:

```bash
h2a record https://example.com --name demo_task
```

بعد التفاعل مع الصفحة، اضغط **Stop & save**. سيحفظ المشروع ملف JSON ضمن `workflows/`، مع تحويل قيم الحقول إلى متغيرات حتى لا يحتفظ بما كتبته أثناء التسجيل.

## الأمان والخصوصية

- لا توجد حسابات سحابية أو تحليلات تتبع داخل البرنامج نفسه.
- راجع رابط البداية والمحددات (selectors) قبل مشاركة ملف الـWorkflow، فقد تتضمن معلومات حساسة.
- التشغيل الذي يتضمن كتابة أو نقرًا يتطلب موافقة صريحة من CLI أو الواجهة. MCP يرفض الكتابة افتراضيًا.
- لا تضع لوحة التحكم المحلية على خادم عام ولا تستخدم حسابات مالية أو حساسة في هذه النسخة التجريبية.

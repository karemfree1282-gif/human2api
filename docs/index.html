Human2API v0.5.0

علّم المتصفح أو الكمبيوتر أو هاتف Android مهمة مرة واحدة، وحوّلها إلى REST API وأداة MCP

المميزات الرئيسية

  • محرك متصفح Chromium / Playwright مع التبويبات المتعددة وiframes وحماية كلمات المرور.
  • أتمتة سطح المكتب عبر Windows UIA وmacOS AX وLinux AT-SPI / GTK3.
  • تطبيق Android Companion بموافقة المستخدم الصريحة وجسر ADB المحلي.
  • محرك إصلاح ذكي (Self-Healing) من 4 مستويات مع منع تكرار عمليات الكتابة.
  • متجر أدوات موقع رقميًا بخوارزمية Ed25519 مع سجل تدقيق مشفر.
